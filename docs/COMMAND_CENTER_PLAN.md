# Sightline — Command Center + Productized Plan

> Generated by office-hours + CEO review on 2026-07-10
> Status: APPROVED
> Mode: Startup (freemium + LinkedIn showcase + exit option)

---

## Vision

Sightline'ı "her şey" platformundan → **M&E personelinin günlük üretim aracına** dönüştür.

**12 ay hedefi:**
- 50-100 aktif M&E kullanıcısı
- 5-10 premium ödeyen kullanıcı
- 2-3 NGO ile pilot satış
- LinkedIn'de tanınırlık
- Exit opsiyonu: codebase + users + brand

---

## Dream State

```
MEVCUT → BU PLAN → 12 AY İDEAL

1 kullanıcı    → 3-kapı + landing + pricing → 50-100 M&E kullanıcısı
"Her şey"      → "Ne üreteceksin?"           → Net M&E aracı
LinkedIn yok   → Otomatik LinkedIn draftları  → Tanınırlık + organik büyüme
Ödeme yok      → Manuel premium              → 5-10 ödeyen kullanıcı
Portfolyo      → Productized service         → Exit opsiyonu
```

---

## Premises

1. M&E personeli Sightline'ı bir veri analytics dashboard olarak değil, bir "üretim aracı" (report/proposal builder) olarak görmeli. İlk ekran = "Ne üreteceksin?"
2. LinkedIn showcase stratejisi kalite çıktı üzerine olmalı, özellik üzerine değil. "59 tool'umuz var" değil, "Sudan için 1 saatte ECHO HIP proposal taslağı" paylaşımı.
3. Freemium limiti doğru ayarlanmalı: M&E personeli 1 proposal denesin (free), kalitenin görüp premium'a geçsin.
4. Şu anki en büyük risk teknik değil, dağıtım. Sightline çalışıyor. Sorun "daha fazla feature" değil, "1 M&E personelin bunu deneyip 'bunu kaybetsem üzülürüm' demesi".

### Phase 4: LinkedIn Content Engine (1 gün)

**Hedef:** Haftalık bulletin'den otomatik LinkedIn post draft'ları.

```
Weekly Bulletin JSON (hazır)
  → scripts/generate_linkedin_content.py
    → LLM: bulletin → 1 main post + 3 crisis posts (TR + EN)
    → DB: linkedin_drafts table
  → Admin panel: "LinkedIn Drafts" tab
    → Review / Edit / Copy / "Posted" işaretle
```

**Post formatı:**
```
🚨 Sightline Haftalık İnsani Durum Bülteni

Bu hafta {N} ülke, {M} rapor analiz edildi:

📌 {Country 1}: {1-line summary}
📌 {Country 2}: {1-line summary}
📌 {Country 3}: {1-line summary}

Detaylı analiz: YOUR_PROJECT_ID.com

#humanitarian #relief #Sightline
```

**Teknik:**
- `scripts/generate_linkedin_content.py`: Cron (Mon 08:00 UTC)
- `server.py`: GET/POST/PUT `/api/admin/linkedin/drafts`
- `chats.db`: `linkedin_drafts` tablosu
- Admin tab'ında "LinkedIn Drafts" sub-tab
- Otomatik post yok — draft + manuel copy-paste

## Phase 1 — Detailed Implementation Spec

### Hedef

SPA'nın "home" tab'ı, mevcut dashboard (harita + weekly brief + walkthrough) yerine **Command Center** olur: 3 üretim kapısı + alt sekmeler. Mevcut dashboard "Kriz Haritası" adıyla erişilebilir kalır.

### Mimari Değişiklik

```
MEVCUT home tab:
  - Full-screen Leaflet harita (80vh)
  - Weekly brief özeti
  - Bento grid stats
  - Platform walkthrough (4 feature + CTA)
  - Promo block (logged-out users)

YENİ home tab (Command Center):
  - Hero: "Ne üreteceksin?" başlığı
  - 3 kapı kartı:
      📋 Durum Raporu (→ SITREP tab)
      📝 Donor Proposal (→ Proposal tab)
      📊 Haftalık Bülten (→ Bulletin tab)
  - Alt: "Kriz Haritası" butonu (→ eski dashboard content)
  - Eski dashboard content (harita, weekly brief, walkthrough) →
      yeni "panel-crisis-map" panel'ine taşınır, Command Center'dan butonla açılır
```

### İçerik Akışı

#### Kapı 1: Durum Raporu (SITREP)
```
Kullanıcı "Durum Raporu" kartını görür
  → Ülke dropdown'ı (mevcut /api/db/countries)
  → Date range (default: son 7 gün)
  → "Rapor Oluştur" butonu
  → Tıkla → switchTab('sitrep') + auto-fill country + auto-run
```

#### Kapı 2: Donor Proposal
```
Kullanıcı "Donor Proposal" kartını görür
  → "Yeni Proposal Oluştur" butonu
  → Varsa mevcut proposal'lar listelenir (en son 3)
  → Tıkla → switchTab('proposal') + create modal aç
```

#### Kapı 3: Haftalık Bülten
```
Kullanıcı "Haftalık Bülten" kartını görür
  → Son bulletin özeti (week label + top 3 crisis)
  → "Tam Bülteni Gör" butonu
  → Tıkla → switchTab('bulletin')
```

#### Alt: Kriz Haritası
```
Kullanıcı "Kriz Haritası" butonunu tıklar
  → Eski panel-home içeriği açılır (harita + weekly brief + walkthrough)
  → Bu, mevcut loadDashboard() fonksiyonunu çağırır
  - panel-home → panel-crisis-map olarak rename
  - TAB_NAMES'e 'crisis-map' eklenir
  - GATED_TABS'te değil (public, herkes görebilir)
```

### Hata Senaryoları

| Senaryo | Ne olur | Çözüm |
|---|---|---|
| Kullanıcı authed değil, kapı tıklar | `switchTab` login panel gösterir | Mevcut freemium preview |
| Ülke listesi boş | Dropdown boş | `loadCommandCenter()` fallback: "Veri yükleniyor..." |
| Bulletin yok | Kapı 3'te "Henüz bülten yok" | Empty state mesajı |
| Proposal yok | Kapı 2'de sadece "Yeni Proposal" butonu | Mevcut empty state |
| Mobil ekran | 3 kolon → 1 kolon | `@media (max-width: 768px) { grid-template-columns: 1fr; }` |
